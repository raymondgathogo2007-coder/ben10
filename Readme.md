# Ray G Photography

This project is a clean, responsive photography portfolio for a landscape and travel photographer. It is designed to showcase a small selection of work in a simple editorial layout, with a strong focus on imagery, minimal typography, and a calm, natural aesthetic.

The page includes:
- a short intro section with the photographer's name and location
- a selected-work gallery for featured images
- an about section with a brief personal description
- a footer with location and contact information
- responsive styling for desktop and mobile screens

## Preview

Open `index.html` in a browser to view the site locally. No build tools, frameworks, or package installation are required.

## Project files

- `index.html` contains the page structure, text content, and image sources.
- `style.css` contains the visual design, spacing, typography, and responsive layout rules.

## Customize

- Update the photographer name, location, bio, and email in `index.html`.
- Replace the sample Unsplash image URLs with your own work.
- Adjust colors, margins, fonts, and breakpoints in `style.css` to match your preferred style.
- Add more gallery items or sections if you want to expand the portfolio.

## Notes

The current gallery uses stock images from Unsplash, so an internet connection is needed for the photos to load correctly. To make the portfolio fully personal, replace these with your own photography and branding.
