# Ray G Photography

A simple, responsive portfolio page for landscape photography. The site includes a short introduction, a selected-work gallery, an about section, and an email contact link.

## Preview

Open `index.html` in a web browser. No build step or package installation is required.

## Project files

- `index.html` contains the page content and image links.
- `style.css` contains the layout and responsive styles.

## Customize

- Replace the sample photographer name, location, biography, and email address in `index.html`.
- Update the gallery image URLs and alt text to use your own photographs.
- Adjust colors, spacing, and breakpoints in `style.css`.

Gallery photographs are currently loaded from Unsplash, so an internet connection is needed to display them.
